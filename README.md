# turnos-kmp-app

Aplicación Android del sistema distribuido de turnos, desarrollada con Kotlin
Multiplatform. Permite registrarse, buscar profesionales, ver disponibilidad, reservar
y administrar las propias reservas.

Forma parte del sistema junto con
[turnos-catalog-service](https://github.com/Final-Programacion-II/turnos-catalog-service)
y [turnos-appointments-service](https://github.com/Final-Programacion-II/turnos-appointments-service).

Documentación en [`docs/`](docs/).
